Click on the question to see the answer! 

<details>
<summary>Where do I download mods for Tomodachi Life: Living the Dream?</summary>

We encourage everyone to post mods directly on **GameBanana**, you can find all kinds of mods there.

<LinkCard
  title="Open GameBanana"

<details>
<summary>My game is crashing after installing a mod</summary>
Some mods may require an [resource size patch](/living-the-dream/creating-mods/rstb-patching/) to work or may not be compatible with your game version, make sure to read the mod description carefully and check if there are any special instructions for installing the mod.
</details>

<details>
<summary>Is there any risks on using mods?</summary>
When used correctly there is no risk on using mods, specially when played offline on a **EmuMMC** or with a emulator. 
</details>

<details>
<summary>Is mod X compatible with mod Y?</summary>
A good way to test that is by downloading both mods and putting both of them in the same folder, if it asks to replace any file then the mods are not compatible with each other.
</details>
